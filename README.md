# Meeting-Scheduler-Requirements

This is a deliverable for the implementation of a meeting scheduler software. This document has atomic requirements, risk model, UML Class Diagram, UML Sequence Diagram and a goal model. The goal of this document is to create a meeting scheduler software that can easily create meetings with people who are in different locations. 


## Features
- Atomic requirements that define what the meeting scheduler software should do
- Risk model that analyzes potential user risks that can happen when using the software
- UML Class Diagram which shows how different components of the software interact with each other
- UML Sequence Diagram which shows how to schedule a meeting and reschedule a meeting
- Goal model which shows the goals the software should achieve when it is used



## Tech Stack
- The meeting scheduler software would be implemented in Java.

# Meeting-Scheduler-Requirements

This repository contains a requirements and design document for a meeting scheduler application. It includes atomic requirements, a risk model, UML Class Diagram, UML Sequence Diagram, and a goal model for a system that helps users schedule meetings across different locations.


## Features
- Atomic requirements that define expected behavior and constraints of the meeting scheduler
- Risk model analyzing potential user risks and mitigation strategies
- UML Class Diagram showing how core components of the system interact
- UML Sequence Diagram illustrating how to schedule and reschedule a meeting
- Goal model outlining the high-level goals the software should achieve


 ## Tech Stack
- Intended implementation language: Java



## What I Implemented
- Defined atomic software requirements for the meeting scheduler
- Created a risk model to analyze user risks and mitigations
- Designed a UML Class Diagram using Java-like syntax to model core entities and interactions
